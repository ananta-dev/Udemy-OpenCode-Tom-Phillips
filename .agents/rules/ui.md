# UI Component Rules

All components in this app must use **shadcn/ui** components. Do not create custom components.

- If a suitable shadcn/ui component is not yet installed, check the [shadcn/ui registry](https://ui.shadcn.com) and install the appropriate component before proceeding.
- Never build custom UI elements (buttons, modals, inputs, etc.) when a shadcn/ui equivalent exists or can be installed.
- Follow shadcn/ui conventions for styling and theming using Tailwind CSS.
